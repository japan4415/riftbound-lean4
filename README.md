# riftbound-lean4

Riftbound（Riot Games のトレーディングカードゲーム）のルールを Lean 4 で形式化するプロジェクトです。公式ルール（Core Rules と Tournament Rules）に則って全カードの効果をコード化し、その性質を小さいところから証明していきます。

- 要求: [docs/original.md](docs/original.md)
- 実装方針: [docs/design.md](docs/design.md)
- 文書の一覧: [docs/README.md](docs/README.md)
