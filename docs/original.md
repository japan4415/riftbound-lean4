# Riftbound Lean4

このリポジトリはRiftboundのルールをLean4で書かれたコードで表現するリポジトリです。
ルールは公式のルールに則り、新カードの追加時にはその効果を反映できるようにする。

## 実装の方針
- Lean4で実装する
- 小さいところから証明を積み上げて実装を行う
- 最終目的は全カードのルールをコード化し、カードでできること全てができる様にすること
